# 2026-09-04

## 修复 frontend（TraeWork 复刻壳）dev 启动白屏

**根因**：启动时渲染层立即调 `refreshSessions()`，此时 Python 后端（ws_bridge.py）尚未就绪，主进程 `request()` 5 秒超时返回 `{ error: 'backend timeout' }` 对象；store 未做数组校验直接存入 `sessions`，`TaskTree` 执行 `sessions.map` 抛 TypeError，React 整树崩溃 → 白屏。

**修复（frontend/）**：
- `store/agentStore.ts`：`refreshSessions` 与 `handleEvent('sessions')` 均增加 `Array.isArray` 校验。
- `hooks/useAgentStream.ts`：`window.agent` 未就绪时跳过订阅；WS `connected` 后自动补一次会话列表查询。
- `main/index.ts`：`request()` 超时返回 `null`（原 `{error}` 对象会让面板显示 [object Object]）。
- 新增 `components/common/ErrorBoundary.tsx` 并包裹 App——以后渲染异常不再白屏，显示错误信息 + 重载按钮。

**顺带修复后端启动崩溃（agents/）**：
- `task_manager.py` / `teammate_manager.py`：裸 `mkdir(exist_ok=True)` 在目录已存在时被运行环境文件代理误报 EEXIST 导致进程退出，改为先 `exists()` 判断再创建。

**验证**：`npm run typecheck` 通过；用纯 Vite(5174) + Electron（`--disable-gpu --no-sandbox` + `ELECTRON_ENABLE_LOGGING=1`）诊断环境实测，渲染层无报错、后端初始化无 traceback。诊断用 `vite.diag.config.mjs` 已删除。

**诊断技巧**：Electron 白屏抓渲染层报错用 `ELECTRON_ENABLE_LOGGING=1`（renderer console 直接打到终端）；本机 shell 有 HTTP_PROXY 环境变量，curl 本地端口需 `--noproxy '*'`。
