# 2026-09-10

## 模型管理重构（Reasonix 式：连接为中心 + 远端刷新）

**背景**：DeepSeek 上新模型，但客户端模型名只能从预置下拉里选、不能改 → 用不了新模型。按 Reasonix 的模型维护界面重构。

### 后端 `agents/llm_config.py`（重写）
- `llmconfig.json` 升级为 **v2：`connections[]` → `models[]` 两级**（连接承载 `base_url`/`api_key`/`api_format`/`compat`，模型承载 `model`/`capabilities`/`context_in|out`/`advanced`）。
- **v1 自动迁移**：读到扁平 `models[]` 时按 `(provider, base_url, api_key)` 聚合为连接并就地写回 v2（幂等）；同时把 `advanced.context_in/out` 提升为模型级字段。
- **扁平兼容视图**：`get_config()` 额外下发 `models[]`（补 `connection_id`/`provider`/`base_url`/`api_key`），输入区下拉、会话绑定、`resolveModelMeta`、`apply_to_env` 零改动。
- **预置厂商元数据外置** `~/.aigent/providers.json`（`_DEFAULT_CATALOG` 内置，首跑物化）；加载时「内置为底 + 文件逐条覆盖 + 结果自愈回写」，官方上新自动补进旧文件。
- 新增 `normalize_base_url()`（裁掉 `/chat/completions` 等）、`fetch_remote_models()`（urllib 直连 `GET {base}{models_path}`，支持自定义路径与 HTTP 错误回显）。
- 模型条目不再冗余存端点/密钥（清理 v1 遗留字段）。

### 协议 / 前端
- 新 WS 命令 `llm_models_fetch` → `llm_models`；IPC `agent:llmModelsFetch`（`request()` 加 `timeoutMs`，此处 30s）；浏览器回退桥 `browserAgent.ts` 同步实现。
- `ModelSettings.tsx` 重写为 **master-detail**（左连接列表 + 右详情：API 地址/格式/Key + 模型列表（勾选=启用、点名=设为当前、⟳刷新、添加模型）+ 兼容设置 + 底部保存栏，改动先落草稿）。
- 新增 `Settings/AddProviderModal.tsx`（推荐预设 / 自定义供应商）、`AddModelModal.tsx`（模型 ID 自由输入 + 参数 + 能力 + 来源）、`ModelListEditor.tsx`、`llmShared.tsx`。
- `agentStore`：`saveLlConfig` 入参改 `LlmConfigPayload`、新增 `fetchModels`、`resolveModelMeta` 支持自定义模型、新增 `providerDot`。
- 文档同步：`06`（重写）、`03`（协议/IPC 行）、`05`（providers.json）、`00-README`。

### 踩坑记录（重要）
- **同一消息里对同一文件发多个 Edit 会互相覆盖**（后一个基于旧快照写入，前一个改动丢失）。同一文件的多处修改必须**串行**发。
