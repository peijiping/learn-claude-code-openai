## 修复：模型下拉列表项名称居中（二次修正）
- 第一轮误判：以为只是 out/ 产物过期，重建后用户反馈仍居中。
- 真正根因：`.model-menu-name` 是 `flex:1` 撑满整行的 span，Chromium 对 button 的 UA 默认 `text-align: center` 会**继承**进 span，导致文字在 span 内居中；`justify-content: flex-start` 只管 flex 项目排布，管不到文字对齐。项目 global.css 的 button 重置未覆盖 text-align。
- 修复：chat.css 给 `.model-menu-name` 加 `text-align: left`（带注释防回归），重建通过，out/ 已只有新 hash 资产。
- 教训：button 内文字居中优先查 UA 的 `text-align: center` 继承，与 justify-content 是两回事。
